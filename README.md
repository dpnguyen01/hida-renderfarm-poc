# HIDA/EEL Render Farm POC — Strategy

Internal working document for the HIDA/EEL render farm proof of concept on **AWS Deadline Cloud**.

**Audience:** Don and Greg (internal), ahead of re-engaging the professors and AWS.

## Contents

- **Phased strategy** — Phase 0 (verify current access + $200 spend), Phase 0.5 (publish & align with Don/Greg), Phase 1 (first professor deployment), Phase 2 (expand with Lorena's AWS product team into heavier jobs).
- **What $200 buys** — the three-component cost model (EC2 + Deadline Cloud mgmt fee + UBL) and a realistic POC envelope.
- **DCC support matrix** — how HIDA's tools (Maya, Houdini, Arnold, V-Ray, Redshift, Blender, Karma, RenderMan, …) map onto Deadline Cloud's service-managed fleet support tiers.
